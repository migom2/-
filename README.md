# 영단어 암기장 (TOEIC 800~900)

순수 HTML/CSS/JS로 만든 영단어 암기 웹사이트입니다. 빌드 도구 없이 `index.html`을 바로 열거나 정적 서버로 배포할 수 있습니다.

TOEIC 800~900점대 필수 어휘 **3,000개**를 **Day 1~30** (하루 100개)으로 구성했습니다.

## 기능

- **📇 플래시카드**: 카드를 클릭해 뜻/예문을 확인하고, "알아요/몰라요"로 학습 상태를 기록합니다. 신규/학습중/암기완료 상태별로 필터링해 학습할 수 있습니다.
- **📝 퀴즈**: 4지선다 객관식으로 단어 뜻을 맞히는 퀴즈입니다. 결과 화면에서 틀린 단어를 다시 확인할 수 있습니다.
- **✍️ 쓰기 연습**: 단어 뜻을 보고 영단어 스펠링을 직접 입력하며 외우는 모드입니다. 정답 확인 후 정확한 스펠링을 바로 보여주고, 오답 목록에서 내가 입력한 답과 정답을 함께 확인할 수 있습니다.
- **📚 단어장**: 단어를 검색하고 상태별로 필터링합니다. 학습 진행 상황을 초기화할 수 있습니다.
- **🗂️ 내 단어장**: 원하는 영단어를 직접 추가할 수 있습니다. 먼저 카테고리를 만들고, 그 카테고리에 단어를 추가하는 방식입니다. 카테고리 이름 변경, 단어를 다른 카테고리로 이동, 단어/카테고리 삭제를 지원합니다.
- **📊 통계**: 전체 암기 완료율, 퀴즈/쓰기 정답률과 함께 Day 1~30 및 내 단어장 카테고리별 암기 완료율을 확인합니다.

상단의 **학습 범위** 선택 상자에서 "전체", 특정 Day, 또는 내가 만든 카테고리를 선택하면 플래시카드·퀴즈·쓰기·단어장이 모두 해당 범위로 필터링됩니다.

퀴즈와 쓰기 연습 결과 화면에서는 "틀린 것만 다시 풀기"와 "전체 다시 풀기" 중에서 선택할 수 있습니다.

학습 진행 상황은 브라우저의 `localStorage`에 저장되어 새로고침해도 유지됩니다.

## 사용법

빌드나 설치 과정 없이 `index.html`을 브라우저로 열면 바로 실행됩니다. 정적 호스팅(GitHub Pages 등)에 그대로 올려도 동작합니다.

```bash
# 로컬에서 확인하고 싶다면 아무 정적 서버로 실행해도 됩니다.
npx serve .
```

## 구성 파일

- `index.html` — 페이지 구조 (학습 범위 선택 상자 포함)
- `style.css` — 스타일
- `words.js` — TOEIC 800~900 기본 단어 데이터 3,000개 (`{ id, en, ko, day, example }`, day: 1~30)
- `app.js` — 플래시카드/퀴즈/쓰기 연습/단어장/내 단어장/통계 로직, 학습 범위 필터링, 진행 상황 저장

기본 제공 단어를 추가하거나 수정하려면 `words.js`를 편집하면 됩니다. 각 항목은 `id`(고유 번호), `en`(영단어), `ko`(뜻), `day`(1~30), `example`(예문)로 구성됩니다.

내가 직접 추가한 단어와 카테고리는 브라우저의 `localStorage`(`vocab-custom-words-v1`, `vocab-custom-categories-v1`)에 저장되며, "🗂️ 내 단어장" 탭에서 추가·정리·삭제할 수 있습니다.
