# 중국어 단어장 (HSK 3~4급)

순수 HTML/CSS/JS로 만든 중국어 단어 암기 웹사이트입니다. 빌드 도구 없이 `index.html`을 바로 열거나 정적 서버로 배포할 수 있습니다.

HSK 3~4급 수준 필수 어휘 **3,000개**를 **Day 1~100** (하루 30개)으로 구성했습니다.

## 기능

- **📇 플래시카드**: 카드 앞면에 **병음**만 보여주고, 클릭하면 **한자 + 병음 + 뜻**이 뒷면에 나타납니다. "알아요/몰라요"로 학습 상태를 기록하고, "이전/다음"으로 자유롭게 넘겨볼 수 있습니다. 신규/학습중/암기완료 상태별 필터링을 지원합니다.
- **📝 병음 퀴즈**: 한자와 뜻을 보고 알맞은 병음(성조 포함)을 5지선다로 고르는 객관식 퀴즈입니다.
- **🎯 성조 게임**: 한자와 뜻을 보고, 성조 표시가 없는 병음에 음절마다 1~4성/경성을 골라 맞히는 게임입니다. 정답 확인 후 각 음절이 맞았는지 틀렸는지, 정답 성조가 무엇인지 바로 보여줍니다.
- **📚 단어장**: 한자·병음·뜻으로 검색하고 상태별로 필터링합니다. 학습 진행 상황을 초기화할 수 있습니다.
- **📊 통계**: 전체 암기 완료율, 퀴즈·성조게임 정답률과 Day 1~100별 암기 완료율을 확인합니다.

상단의 **학습 범위** 선택 상자에서 "전체" 또는 특정 Day를 선택하면 플래시카드·퀴즈·성조 게임·단어장이 모두 해당 범위로 필터링됩니다.

퀴즈와 성조 게임 결과 화면에서는 "틀린 것만 다시 풀기"와 "전체 다시 풀기" 중에서 선택할 수 있습니다.

학습 진행 상황은 브라우저의 `localStorage`에 저장되어 새로고침해도 유지됩니다.

## 사용법

빌드나 설치 과정 없이 `index.html`을 브라우저로 열면 바로 실행됩니다. 정적 호스팅(GitHub Pages 등)에 그대로 올려도 동작합니다.

```bash
npx serve .
```

## 구성 파일

- `index.html` — 페이지 구조 (학습 범위 선택 상자 포함)
- `style.css` — 스타일
- `words.js` — HSK 3~4급 수준 단어 데이터 (`{ id, hanzi, pinyin, ko, day }`, day: 1~100)
- `app.js` — 플래시카드/병음 퀴즈/성조 게임/단어장/통계 로직, 학습 범위 필터링, 진행 상황 저장

### `words.js` 데이터 형식

각 항목은 `id`(고유 번호), `hanzi`(한자), `pinyin`(성조 포함 병음, 한자 한 글자당 음절 하나씩 공백으로 구분), `ko`(뜻), `day`(1~100)로 구성됩니다.

```js
{ id: 1, hanzi: '学习', pinyin: 'xué xí', ko: '공부하다, 배우다', day: 1 }
```

병음은 반드시 한자 글자 수와 음절 수가 1:1로 맞아야 성조 게임이 올바르게 동작합니다 (예: `认为` → `rèn wéi`).

기본 제공 단어를 추가하거나 수정하려면 `words.js`를 편집하면 됩니다.
