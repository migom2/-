# 영단어 암기장

React + Vite로 만든 영단어 암기 웹사이트입니다.

## 기능

- **📇 플래시카드**: 카드를 클릭해 뜻을 확인하고, "알아요/몰라요"로 학습 상태를 기록합니다. 신규/학습중/암기완료 상태별로 필터링해 학습할 수 있습니다.
- **📝 퀴즈**: 4지선다 객관식으로 단어 뜻을 맞히는 퀴즈입니다. 결과 화면에서 틀린 단어를 다시 확인할 수 있습니다.
- **📚 단어장**: 전체 단어 목록을 검색하고 상태별로 필터링합니다. 학습 진행 상황을 초기화할 수 있습니다.
- **📊 통계**: 암기 완료율, 퀴즈 정답률 등 학습 현황을 한눈에 확인합니다.

학습 진행 상황은 브라우저의 `localStorage`에 저장되어 새로고침해도 유지됩니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버 실행
npm run build    # 프로덕션 빌드
npm run lint     # 린트 검사
```

## 단어 데이터 추가/수정

`src/data/words.js` 파일에 단어 객체(`{ id, en, ko, level, example }`)를 추가하거나 수정하면 됩니다.
